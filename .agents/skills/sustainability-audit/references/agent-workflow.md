# Agent-triggered audit workflow

The version-matched workflow is served by `audit/cli.py skills get core` in the resolved runtime checkout. Follow the entry skill to resolve that checkout, then load `setup`, `collection`, the three review roles and `report` only when needed. The CLI owns deterministic tools and handoff validation; the host agent owns conversation, native delegation and judgment.

Keep session output in the audited project, outside the plugin cache. New audits default to 5–10 representative pages. Use high reasoning for GPT-6.1 Sol and DeepSeek V4.1 Flash. Preserve the actual settings and explicit sequential fallback when delegation is unavailable.
