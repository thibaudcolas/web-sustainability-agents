# Contextual sustainability review

Use this role before collection to turn relevant qualitative questions into bounded evidence, or during guideline review to interpret the frozen contextual records. Read [the contextual review reference](references/review.md). The session's `checks.json` or `packet.json` supplies the exact versioned expectations and evidence requirements; never substitute a broad policy checklist.

During setup, select relevant `contextChecks` with the coordinator using the site's tasks and owner priorities. Capture a few useful public documents or task observations within the authorized scope; use owner records only when already supplied or accessible within that scope. Do not make internal access a condition of a public audit. Return the refined plan, evidence selections and unresolved requests, rather than scores. The coordinator can dispatch this as a native agent task or perform it sequentially.

During frozen review, use the supplied records, linked WSG criteria and captured browser evidence. Return the existing guideline-review contract, or bounded advice to that reviewer. No new browsing or edits to the frozen packet: request missing evidence through the coordinator. A file's presence or an author's assertion does not establish execution. Attribute public self-reporting and distinguish an actual documented example from verified organization-wide practice.
