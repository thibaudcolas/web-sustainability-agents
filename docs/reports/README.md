# Example audit reports

Read one report per site. The current WIP reports use the same versioned check catalog, but their findings still need owner review. Neither report is a whole-site sustainability certification.

| Current report                                                        | Sample                                                                                  | Review focus                                                             |
| --------------------------------------------------------------------- | --------------------------------------------------------------------------------------- | ------------------------------------------------------------------------ |
| [guide.wagtail.org](../initial-implementation/guide-breadth-audit.md) | Three pages, seven supplemental states per page, one completed journey, selected source | Search semantics, preferences, source-informed fixes and useful unknowns |
| [wagtail.org](../initial-implementation/wagtail-breadth-audit.md)     | Three pages, seven supplemental states per page, one completed journey, selected source | Disclosure interpretation, preferences, media and source-informed fixes  |

Each report leads with first-load measures and a scoped score, then priorities, quantitative evidence, qualitative findings, next auditing steps and reproducibility. Linked bundles preserve the evidence and judgments behind the report. See [how to read the score](../knowledge-base/audit-scoring.md) and [current check coverage](../reference/checks.md).

For feedback, identify the site and check ID, then explain whether the problem is the observed fact, missing evidence, interpretation, priority or proposed fix. We can trace that feedback to a collector, skill, rubric or eval case.

## Earlier experiments

These pages preserve previous samples and methods. Their scores and totals should not be compared directly with the current reports.

- [Earlier guide audit](../initial-implementation/guide-audit.md) and [earlier Wagtail.org audit](../initial-implementation/wagtail-audit.md): previous staged measurements, annual scenarios and two-page agent pilots.
