# Knowledge base

Reusable methodology and engineering reference material for web sustainability audits. Dated source observations and known limitations remain attached to each topic. Project proposals belong in the [feasibility study](../feasibility-study/README.md); executed experiments and development plans belong in [initial implementation work](../initial-implementation/README.md).

- [WSG and STAR as an audit foundation](wsg-and-star.md): publication status, methodology, machine-readable sources, and measurement limits.
- [Digital Carbon Ratings](digital-carbon-ratings.md): integration with SWDM v4, versioned thresholds, and interpretation alongside WSG findings.
- [Deterministic audit tools](deterministic-tools.md): existing measurement tools, browser instrumentation, capture protocols, and evidence boundaries.
- [Browser energy and traffic scenarios](energy-and-traffic.md): co2-runner and sitespeed.io counter boundaries, CrUX rank lookup, and population-based pageview estimates.
- [Scoped audit scoring](audit-scoring.md): ACT outcome mapping, WSG impact points, STAR scoring context, explicit denominators and coverage limits.
- [Lessons from existing audit projects](local-projects.md): reusable patterns and limitations from claude-seo and accessibility-agents.
- [Model providers and inference accounting](provider-capabilities.md): generative and decision APIs, versioning, confidence semantics, and measurement boundaries.
