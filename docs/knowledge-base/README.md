# Knowledge base

Reusable explanations of web sustainability methodology, evidence and tooling. Start here to understand what an audit result means; use [the audit guide](../using/README.md) to run one. Implementation-specific commands and data contracts live in the [workflow](../using/workflow.md) and its linked references.

## Methodology and interpretation

- [WSG and STAR](wsg-and-star.md): scope, publication status, source formats and evaluation limits.
- [Scoped audit scoring](audit-scoring.md): outcome mapping, impact weights, denominators and coverage.
- [Assessment crosswalk](assessment-crosswalk.md): migration of the older assessment to current WSG evidence routes; planned routes are not implemented checks.
- [Digital Carbon Ratings](digital-carbon-ratings.md): SWDM v4, thresholds and interpretation alongside WSG findings.
- [Carbon.txt evidence](carbon-disclosures.md): discovery, provider relationships, declarations and corroboration.

## Measurement and tools

- [Deterministic audit tools](deterministic-tools.md): existing collectors, browser instrumentation and capture protocols.
- [Browser energy and traffic scenarios](energy-and-traffic.md): counter boundaries, CrUX ranks and pageview estimation.
- [Optional GreenFrame measurements](greenframe.md): client-side scenario boundaries and remaining runner validation.

## Agent engineering

- [Portable agent orchestration](agent-orchestration.md): the Wagtail CLI precedent, native subagents, durable handoffs and remaining design decisions.

- [Lessons from existing audit projects](local-projects.md): patterns from claude-seo and accessibility-agents.
- [Model providers and inference accounting](provider-capabilities.md): API contracts, versioning, confidence and measurement boundaries.

Project hypotheses belong in the [feasibility study](../feasibility-study/README.md). Executed live results belong under [reports](../reports/README.md); model experiments belong in the [evaluation project](../evaluation/README.md). Source observations and limitations stay attached to each reference topic.
