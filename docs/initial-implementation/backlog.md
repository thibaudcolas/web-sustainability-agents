# Implementation backlog

The [project assessment](project-assessment.md) explains the gaps; the [roadmap](validation-roadmap.md) defines release gates. This page owns actionable work. IDs stay stable so report feedback and benchmark failures can refer to the component that needs to change.

“Implemented” below means a foundation exists, not that its quality or portability is independently established. Preserve published captures and campaign results; corrections create new versions.
