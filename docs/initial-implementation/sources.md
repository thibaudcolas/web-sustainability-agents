## Scoped scoring and skill-guided review

The [scoring research](../knowledge-base/audit-scoring.md) uses [ACT Rules Format 1.1](https://www.w3.org/TR/act-rules-format/) for outcome-mapping distinctions, [WSG Impact Ratings](https://www.w3.org/TR/wsg-ir/) for guideline priority points, and [STAR](https://w3c.github.io/sustainableweb-ig/docs/star.html) for evaluation/reporting context. None is presented as prescribing our website score. ACT's inspected version is the February 2026 Recommendation; WSG and its impact ratings use the October 2026 drafts. All 71 impact-point values were extracted by matching WSG fragment identifiers to the corresponding rating tables; `audit/impact-weights.json` retains the source version and fetched HTML digest.

The project-owned `scoped-wsg-v1` rubric supports 21 bounded guideline groups. Two independent GPT-6.1 Sol/low reviewers applied evidence-review 0.4.0, guideline-review 0.1.0 and claims-review 0.1.0 to the raw site artifacts and supplied source. They were instructed not to read the prior human report conclusions. The coordinator inspected their judgments, including the new eager-logo finding, and retained their outcomes. This tests actual skill execution; it does not isolate a causal skill benefit or provide owner-validated reference labels.

The [review artifact](assets/skill-reviews.json) includes original judgments, evidence locations, source/rubric/skill hashes and raw-review digests. The deterministic publisher resolves citations to existing JSON nodes and checks their enclosing site; explicit repository associations permit supplied source corroboration. Historical ecosystem arithmetic is associated with Wagtail.org's disclosure; a related disclosure found during guide discovery remains attributed context. Unverified source deployment is not promoted to attestation.

The [score artifact](assets/scored-audits.json) preserves all 71 guideline rows per site. Unknowns stay in the attempted-check denominator without becoming failures. Repeated observations do not multiply a guideline's weight. Scores reject unresolved evidence references, missing indexed nodes, changed source artifacts and a changed rubric digest. Source semantics still require review; a resolvable citation alone does not establish that it supports the judgment.
